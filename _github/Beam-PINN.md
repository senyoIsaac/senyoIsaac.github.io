excerpt: "This project contains the implementation of a **Physics-Informed Neural Network (PINN)**, a novel machine learning paradigm that integrates physical laws directly into the training process. It demonstrates how a PINN can solve a classic structural mechanics problem—the deflection of a simply supported beam under a uniform load—by learning the underlying differential equation. Instead of relying on a large dataset of pre-solved examples, the model learns by minimizing a loss function that penalizes violations of the governing physics and boundary conditions. This approach showcases a powerful method for solving complex engineering problems where data is scarce but the physical laws are well-understood..<br/><img src='/images/about/pinn_main.jpg'>"
